Share notes between office PCs without the internet

MemilMemo is free sticky notes for your Windows desktop.

Notes travel only between PCs on the same local network. Because it never uses the internet, it also works in offices where internet access is blocked.

1. Install

Download the latest installer and run it, or install it from the Microsoft Store.

If Windows shows "Windows protected your PC", select More info → Run anyway.

For a PC without internet access, copy the installer from another PC and run it. Nothing else needs to be downloaded.

2. Start sharing on one PC

On the PC that will keep the notes, choose "Start sharing from this PC" on the first screen, enter your name, and select Start.

A password is optional. If you set one, only PCs that know it can join.

If Windows Firewall asks for access, allow private networks.

3. Join from the other PCs

On each of the other PCs, choose "Join notes on another PC" on the first screen.

If they are on the same local network, the sharing PC appears under "Found". If it doesn't, enter the address shown in the sharing PC's Participants window.

4. Work together

While someone edits a note, the other PCs show that it is being edited. When they finish, the change reaches every PC, and you can go back to an earlier version in the edit history.

Notices, reminders, and widgets such as polls and calendars are shared between the PCs too.

5. When the sharing PC is off

The other PCs keep a copy of the notes, so you can still read, write, and edit them. When the sharing PC is back on, they reconnect and sync automatically.

If the sharing PC can no longer be used, another PC can take over sharing from its copy.

6. Use it on one PC

To use it without sharing, choose "Use on this PC only" on the first screen.

Later, select "Start sharing" from your profile button at the top right of the main window, and that PC becomes the sharing PC.

7. Internet access

Notes never leave your local network. Only the version installed with the setup file connects to GitHub, to check for and download updates. See the Privacy Policy for details.
