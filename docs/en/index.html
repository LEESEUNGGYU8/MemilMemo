Getting started

  1. InstallDownload the setup file and run it.
  2. Start sharingStart sharing on one PC.
  3. JoinJoin from the other PCs with the sharing PC's address.

If Windows shows "Windows protected your PC", select More info → Run anyway.

Key features

Real-time edit history and restore

Shows who is editing a note, and restores any earlier point from the edit history.

Notices, read receipts, and @mentions

Make any note a notice to see who has read it, and mention participants.

Reminders and scheduled unchecking

Set a reminder on a note to remind the people you choose at a set time and interval.

To-do lists and formatting

Supports checkboxes, bullets, text color, highlighting, images, and tables.

Widgets inside notes

Create a variety of widgets inside a note and use them together.

Shortcut links to files and folders

Put files and folders from a shared folder into a note as links, each marked with an icon for its type.

Folding notes and docking to the screen edge

Fold a note into a slip or an icon, and drag it to the screen edge to dock it as a tab. Unfold it and it returns to where it was.

Folding into desktop icons

Notes and folders folded into icons line up with your other desktop icons, at the same size and spacing.

Folders, tags, and search
Sort notes with folders and #tags, and find them right away in the Find window.
Private
Show a note or a folder only to yourself.
List views
Choose a list or a grid, in three sizes.
Use on this PC only
Use it on this PC without sharing. You can start sharing later.
Quick new notes
Create a note from the desktop right-click menu, the taskbar, or a shortcut, or from text and images on the clipboard.
Calculations and totals
Fills in the result of a line ending in "=", and shows the total and average of selected numbers.
Print and PDF
Preview before printing, or save as a PDF.
Automatic backup and restore
Backs up on the schedule you set, and restores from a backup.
Languages
The app is available in Korean, English, and Japanese.

Frequently asked questions

Internet connection

MemilMemo does not use the internet for its normal work. An internet connection is needed only to check for new versions and to update.

Where notes are stored

The PC that starts sharing keeps the originals, and each PC that joins keeps a copy of part of the notes. No note data is stored on an outside server.

When the sharing PC is off

The other PCs can still write new notes and edit existing ones, working from their copies. When the sharing PC is back on, they reconnect and sync automatically.

Firewall prompt

On the PC that starts sharing, Windows Firewall may ask whether to allow access. Allow it for private networks.

Cost

MemilMemo is freeware. It has no in-app ads, no paid features, and no requests for payment.

Supported systems

MemilMemo runs on PCs with Windows 10 or 11.
