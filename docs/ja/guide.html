メミメモ
한국어 English 日本語

インターネットなしで社内のPC同士でメモを共有する

メミメモは、デスクトップに貼って使う無料の付箋アプリです。

メモは同じ社内ネットワークのPC同士でだけやり取りします。インターネットを使わないので、インターネットが遮断された閉域網のオフィスでも使えます。

1. インストール

最新版のインストーラーをダウンロードして実行するか、Microsoft Storeからインストールします。

Windows が「Windows によって PC が保護されました」と表示したら、詳細情報 → 実行を選びます。

インターネットにつながらないPCには、ほかのPCでダウンロードしたインストーラーを移してインストールします。ほかにダウンロードするものはありません。

2. 1台のPCで共有を始める

メモを保管するPCで、最初の画面の「この PC で共有を始める」を選び、自分の名前を入れて「開始」を押します。

パスワードは入れなくてもかまいません。入れると、パスワードを知っているPCだけが参加できます。

Windows ファイアウォールがアクセスの許可を求めたら、プライベートネットワークを許可します。

3. ほかのPCから参加する

ほかのPCでは、最初の画面の「他の PC のメモに参加」を選びます。

同じ社内ネットワークにあれば「見つかった PC」に共有PCが表示されます。表示されないときは、共有PCの参加者ウィンドウに表示されるアドレスを入れます。

4. 一緒に使う

だれかがメモを編集しているあいだ、ほかのPCには編集中と表示されます。編集が終わるとすべてのPCに反映され、編集履歴から前の内容に戻すこともできます。

お知らせ、通知、投票やカレンダーなどのウィジェットも、共有しているPC同士で一緒に使えます。

5. 共有PCが止まっているとき

ほかのPCでは、受け取っておいたコピーでメモを見たり、新しく書いたり編集したりできます。共有PCをまた起動すると、自動で再接続して同期します。

共有PCがもう使えないときは、ほかのPCが受け取ったコピーから共有を引き継げます。

6. 1台だけで使う

共有せずに使うときは、最初の画面で「この PC だけで使う」を選びます。

あとからメインウィンドウ右上の自分のアイコンで「共有を開始」を選ぶと、そのPCが共有PCになります。

7. インターネット接続

メモが社内ネットワークの外に出ることはありません。インストーラーでインストールした場合だけ、新しいバージョンの確認と更新のためにGitHubに接続します。詳しくはプライバシーポリシーをご覧ください。
