プライバシーポリシー

施行日 2026年11月21日

メミメモは個人情報を収集しません。

保存

メモ、ニックネーム、設定はユーザーの PC にのみ保存します。共有を始めた PC に保存し、参加した PC にも受け取ったメモのコピーを置きます。

送信

メモとニックネームは、同じローカルネットワークで共有に参加した PC 同士でのみやり取りします。開発者や第三者のサーバーには送信しません。

共有を始めた PC は、同じローカルネットワークの PC が共有 PC を探すときに、ニックネームと接続アドレスを知らせます。

インターネット接続

セットアップファイルでインストールしたメミメモは、新しいバージョンの確認とダウンロードのために GitHub に接続します。このとき、メモ、ニックネーム、設定は送信しません。

Microsoft Store からインストールしたメミメモは、この接続を行いません。

分析ツールと広告

利用記録を集めるツール、広告、会員登録はありません。

データの削除

メミメモをアンインストールしてデータフォルダーを削除すると、すべてのデータが消えます。

セットアップファイルでインストールした場合は %APPDATA%\SyncNotes、Microsoft Store からインストールした場合は %USERPROFILE%\MemilMemo です。

お問い合わせ

GitHub のお問い合わせ掲示板にお書きください。

変更

ポリシーを変更したときは、このページに掲載します。
