메밀메모

인터넷 없이 사무실 PC끼리 메모 같이 쓰기

메밀메모는 포스트잇처럼 바탕화면에 붙여 쓰는 무료 스티커 메모입니다.

메모는 같은 내부망의 PC끼리만 주고받습니다. 외부 인터넷을 쓰지 않아서, 인터넷이 막힌 폐쇄망 사무실에서도 쓸 수 있습니다.

1. 설치

최신 버전 설치 파일을 받아 실행하거나 Microsoft Store에서 설치합니다.

Windows가 "PC 보호" 창을 띄우면 추가 정보 → 실행을 누릅니다.

인터넷이 막힌 PC에는 다른 PC에서 받은 설치 파일을 옮겨 와 설치하면 됩니다. 따로 받을 것은 없습니다.

2. 한 PC에서 공유 시작

메모를 보관할 PC 한 대에서 첫 화면의 '이 PC에서 공유 시작'을 고르고, 내 이름을 넣은 뒤 시작을 누릅니다.

비밀번호는 넣지 않아도 됩니다. 넣으면 비밀번호를 아는 PC만 참여할 수 있습니다.

Windows 방화벽이 접근 허용을 물으면 개인 네트워크를 허용합니다.

3. 다른 PC에서 참여

다른 PC에서는 첫 화면의 '다른 PC의 메모에 참여'를 고릅니다.

같은 내부망에 있으면 '찾은 PC'에 공유 PC가 나옵니다. 나오지 않으면 공유 PC의 참가자 창에 보이는 주소를 넣습니다.

4. 함께 쓰기

누군가 메모를 고치는 동안 다른 PC에는 편집 중이라고 표시됩니다. 고치기를 마치면 모든 PC에 반영되고, 수정 이력에서 예전 내용으로 되돌릴 수 있습니다.

공지, 알림, 투표나 달력 같은 위젯도 공유한 PC끼리 함께 씁니다.

5. 공유 PC가 꺼졌을 때

다른 PC에서는 받아 둔 사본으로 메모를 보고, 새 메모를 쓰거나 고칠 수 있습니다. 공유 PC를 다시 켜면 자동으로 다시 연결하고 동기화합니다.

공유 PC를 더 쓸 수 없게 되면 다른 PC가 받아 둔 사본으로 공유를 이어받을 수 있습니다.

6. 혼자 쓰기

공유 없이 한 PC에서만 쓰려면 첫 화면에서 '혼자 쓰기'를 고릅니다.

나중에 메인 창 오른쪽 위의 내 아이콘에서 '공유 시작'을 누르면 그 PC가 공유 PC가 됩니다.

7. 인터넷 연결

메모는 내부망 밖으로 나가지 않습니다. 설치 파일로 설치한 경우에만 새 버전 확인과 업데이트를 위해 GitHub에 접속합니다. 자세한 내용은 개인정보처리방침에 있습니다.

메밀메모 처음으로 변경 내역 문의 개인정보처리방침
