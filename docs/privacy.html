개인정보처리방침

시행일 2026년 11월 20일

메밀메모는 개인정보를 수집하지 않습니다.

저장

메모, 닉네임, 설정은 사용자의 PC에만 저장합니다. 공유를 시작한 PC에 저장하고, 참여한 PC에도 받은 메모의 사본을 둡니다.

전송

메모와 닉네임은 같은 내부망에서 공유에 참여한 PC끼리만 주고받습니다. 개발자나 제3자의 서버로 보내지 않습니다.

인터넷 접속

설치 파일로 설치한 메밀메모는 새 버전 확인과 내려받기를 위해 GitHub에 접속합니다. 이때 메모, 닉네임, 설정을 보내지 않습니다.

Microsoft Store에서 설치한 메밀메모는 이 접속을 하지 않습니다.

분석 도구와 광고

사용 기록을 모으는 도구, 광고, 회원 가입이 없습니다.

데이터 삭제

메밀메모를 제거하고 데이터 폴더를 지우면 모든 데이터가 지워집니다.

설치 파일로 설치한 경우 %APPDATA%\SyncNotes, Microsoft Store에서 설치한 경우 %USERPROFILE%\MemilMemo입니다.

문의

GitHub 문의 게시판에 남겨 주세요.

변경

방침이 바뀌면 이 페이지에 게시합니다.

Privacy Policy

Effective November 20, 2026

MemilMemo does not collect personal information.

Storage

Notes, nicknames, and settings are stored only on your PCs. The PC that starts sharing stores the notes, and each PC that joins keeps a copy of the notes it receives.

Transmission

Notes and nicknames are exchanged only between the PCs that join the same share on your local network. Nothing is sent to servers run by the developer or any third party.

Internet access

MemilMemo installed with the setup file connects to GitHub to check for and download new versions. Notes, nicknames, and settings are not sent.

MemilMemo installed from the Microsoft Store does not make this connection.

Analytics and ads

There are no analytics tools, ads, or accounts.

Deleting your data

Uninstall MemilMemo and delete its data folder to remove all data.

The folder is %APPDATA%\SyncNotes for the setup file version and %USERPROFILE%\MemilMemo for the Microsoft Store version.

Contact

Please use the GitHub issue board.

Changes

Changes to this policy are posted on this page.
